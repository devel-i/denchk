## Запуск

Настольное приложение: открыть `desktop/HrPractice/HrPractice.csproj` в Visual Studio 2022 с компонентом «Разработка классических приложений .NET», восстановить NuGet-пакеты и запустить. Нужна Windows и .NET 8. База создаётся при первом запуске в `%LOCALAPPDATA%/hr-practice-v3.sqlite`. Логины: `isivanov` (администратор) и `papetrov` (пользователь); пароль не нужен по условию задания.

Мобильное приложение: открыть `mobile/BookPractice` в Android Studio с JDK 17, дождаться синхронизации Gradle, запустить на устройстве или эмуляторе Android 8+. Логин: `student`.

В этой Linux-среде нет .NET SDK и Android SDK, поэтому сборка и экранные снимки приложений здесь не выполнялись. Проверки исходников перечислены в отчёте.
